# RustGram

Клиент мессенджера на Rust (grammers, официальный протокол MTProto) + Android-приложение.

- Показ ID аккаунта и публичной информации
- Архив входящих сообщений с пометкой удалённых
- Приватное хранилище данных приложения

Сборка: GitHub Actions собирает APK автоматически (вкладка Actions).
